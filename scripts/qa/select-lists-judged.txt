# Dropdowns built from a fixed list that ALSO show a value out of a record, with no empty option.
#
# Why this file exists. A <select> whose option list does not contain the value it was given
# selects its FIRST option, and a Save that reads the box then writes that first option back. This
# codebase has been bitten by it five times: round 30 (the access matrix calling unknown roles
# "Admin"), fire #115 (the funnel form deleting answers), fire #116 (every company losing where it
# came from), fire #119 (nineteen companies filed as ministries). Each was found by hand, one round
# apart. check-structure now finds every dropdown of that shape and requires each one to be judged
# here, so the sixth is judged when it is written instead of years later.
#
# Written 2026-09-21 (fire #123) after the whole set was classified against the live database.
#
# Format:   <file>:<id or the record field it compares>  :  <verdict, and why>
#
# A verdict must be one of:
#   FILTER      — the compared value is a SCREEN FILTER, not a stored record. Nothing can be lost:
#                 a value outside the list only means the filter starts somewhere else.
#   IN-LIST     — it edits a stored record, and every value the live data holds IS in the list.
#                 Checked against the database; re-check if the list or the data changes.
#   NO-ROWS     — it edits a record type the workspace holds ZERO rows of. It carries the defect,
#                 and must be fixed the way the lead/funnel/airline/entity boxes were (an empty
#                 option, plus the stored value as its own option) BEFORE that feature is first
#                 used in earnest.
#   FIXED       — carries an empty option and an on-file fallback. Such a box no longer matches the
#                 scan at all, so this verdict should never appear here; it is listed for the
#                 reader's sake.
#
# When the check reports a key that is not here, judge it and add a line. When it reports a line
# here that no longer matches anything, delete the line — a stale entry is as misleading as a
# missing one.
