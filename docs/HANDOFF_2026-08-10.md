## 1 · What this is (30 seconds)

**Direct** (دايركت للسفر والسياحة) is a Saudi travel & tourism company. This repo is their
**internal B2B tool** — leads → clients → proposals → finance → reports — used by Direct
employees only, in **Arabic + English**. It is **one ~1.1 MB single-file `index.html`** (vanilla

(payments.directksa.com) owns all real money/invoices/ZATCA; this app mirrors and coordinates.

## 5 · How to work on this app (essential mechanics)

- **Structure:** base render in the middle of `index.html`; enhancements are **layered
  `<script>` blocks appended at the end** (v18…v57), each `(function(){try{…}catch(e){}})()`, most
  wrapping `render` + a `setTimeout` + an idempotency guard (`.vNN-…` class check). Add new work as
  a new layer in that pattern; don't restructure the middle.
- **CSS tokens** live in `:root` near line 12 (`--orange:#FF6B00`, `--bg:#FBF5F0`, `--line:#e7e7e7`,
  `--ink`, …). A `v26_3` block near line ~5784 styles the top bar/chips.
- **Deploy:** `git push -u origin claude/content-audit-pages-f4lenf` then
  `git push origin HEAD:refs/heads/claude/new-session-9fhlp1` → Vercel. Reversible via `git revert`.
- **Verify in the harness, not by reading code:** `scripts/qa/` runs `index.html` headless
  (Playwright/Chromium at `/opt/pw-browsers/chromium-1194/chrome-linux/chrome`) against

## 6 · Learnings & landmines (traps that cost time)

- **The harness serves FAKE data.** Verify UI against real Supabase rows or a screenshot — never
  the mock alone. (This gap has burned multiple sub-sessions.)
- **`me` (global) is the auth session OBJECT after login, not a function** — hence the app's many
  `typeof me==='function'` guards. For the current user's display name use **`meName()`** /
  `DB.settings.currentUser`, not `me()`.
- **Chromium `innerText` returns CSS-`text-transform`ed text** (uppercase headers come back
  uppercase) → use **case-insensitive** regex in harness assertions or you get false negatives.
- **Deep-sweep's 2 "problems" are intentional**, not bugs: the "Convert to client" confirm and the
  Arabic client "Edit" prompt for the Direct client ID. `TOTAL pageerrors: 0` is the real signal.
- **Never call `window.supabase.createClient` in a new layer** — it's memoised (a `v44a` block);
  just call it and you get the shared client. Five clients once fought over token refresh.
- **New pages need a `buildNav` entry**, not just a render branch (a ledger sat unreachable for two
  days). **Saves are partial** (`v45` `save_state_patch` by changed section).
- **`app_state` blob** still holds `requests/offers/projects/bookings/invoices` (per-section saves;
  same-section concurrent edits = last-write-wins). `businesses/contacts/finance_*`/`funnels`/
  `app_users` are real tables.
- **Sandbox can't open URLs** (directksab2b.com, *.supabase.co, corporate-admin) — WebFetch is
  blocked for these. **Google Drive works** and is the way to get files/HTML/CSS.
- **Subagents are banned** (credits, June 2026). Don't spawn them.
- **Never put the model id in commits/PRs/code** — chat only.
