away.
Not blocking: it is a setting (`app.default_theme`).

**Q34 — Partnership stages.** Today (V80): Prospect → Meeting → Proposal → Signed, the partner Active at Signed. The calls
suggest Prospect → Contacted → Demo → Proposal (optional, may be skipped) → Signed → Onboarded, with the partner Active
only at Onboarded. *Recommended:* **yes** — it matches how deals actually run, and the Corporate onboarding checklist
(V89) then closes the Onboarded stage. It costs one flag: stages are already a settings list; a stage marked
"optional" may be skipped without being recorded as passed.

**Q35 — A Direct ticket or booking reference as evidence.** Today an achievement's evidence is a file (V33, V68).
*Recommended:* **yes** — a reference from Direct's own systems (booking, invoice, ticket — `work.ref_system`) counts as
evidence alongside files, checked against its system's format and opening as a link, so a person does not screenshot
what the system already holds.

**Q36 — When an integration counts.** *Recommended:* the "technical integration" achievement counts at **handover to
Product** (the ticket raised is its evidence, dated then); the integration's go-live is a separate date on the same
achievement that never counts it again, and a tracked-only KPI follows go-lives.
